# NewLife.Panasonic 架构设计

> 版本：v2.0 | 日期：2026-07-22
> 需求对应：[需求文档](需求文档.md) | 功能清单：[功能清单](功能清单.md)

## 1. 整体架构

本项目为单一类库工程，基于 NewLife IoT 驱动模型实现松下 PLC 协议，支持三种通信方式。
整体架构如下：

```mermaid

    subgraph 消费方
        IoTEdge[IoTEdge 边缘网关]
        ZeroIoT[ZeroIoT 平台]
        用户代码[用户 .NET 应用]
    end

    subgraph NewLife.Panasonic
        Driver[PanasonicDriver<br/>Modbus TCP / RTU]
        Mewtocol[MewtocolDriver<br/>Mewtocol TCP]
        Node[PanasonicNode]

    end

    subgraph 依赖层
        NewLife.IoT[NewLife.IoT<br/>标准接口]

        NewLife.ModbusRTU[NewLife.ModbusRTU<br/>串口Modbus]
        NewLife.Core[NewLife.Core<br/>核心工具]
    end

    subgraph 目标设备
        PLC[松下 PLC<br/>Modbus TCP/RTU 网关]
        PLCMew[松下 PLC<br/>Mewtocol 直连]
    end

    消费方 --> Driver
```

### 设计原则

- **接口驱动**：基于 `NewLife.IoT` 定义的标准接口（`IDriver`、`INode`、`IDriverParameter`）实现，保证与 IoTEdge、ZeroIoT 等平台的即插即用。
- **继承复用**：基于 Modbus 的驱动继承 `ModbusDriver` 复用 Modbus 协议栈，仅需实现通道创建逻辑。
- **最小依赖**：尽量依赖 NewLife 生态基础包，新增协议时按需添加依赖。
- **场景覆盖**：同时支持 Modbus TCP、Modbus RTU 串口、Mewtocol 原生协议三种通信方式。

## 2. PLC — 松下PLC协议驱动

### 2.1 职责

| 职责 | 说明 |
|------|------|
| 松下 PLC 设备通信 | 通过 Modbus TCP / Modbus RTU / Mewtocol TCP 等协议与松下 PLC 通信 |
| 驱动注册发现 | 通过 `[Driver]` 特性实现驱动自动发现 |
| 连接参数管理 | 管理 TCP 地址、串口参数、站号、功能码、协议标识等连接参数 |
| 连接健康管理 | 内建心跳检测和自动重连机制（仅 TCP 模式），提高工业场景稳定性 |

### 2.2 核心组件

| 组件 | 所在工程 | 对应编码 | 说明 |
|------|----------|:-------:|------|
| `PanasonicDriver` | `NewLife.Panasonic` | PLC-1 / PLC-5 / PLC-6 | 统一驱动入口，继承 `ModbusDriver`，实现 `IDriver`。根据参数自动选择 Modbus TCP 或 Modbus RTU；内建心跳检测和自动重连（仅 TCP） |
| `PanasonicNode` | `NewLife.Panasonic` | PLC-2 | Modbus 设备节点，实现 `INode`。承载 `Modbus`、`Host`、`ReadCode`、`WriteCode`、`Driver`、`Device`、`Parameter` 等运行状态 |
| `PanasonicParameter` | `NewLife.Panasonic` | PLC-3 / PLC-6 | 统一连接参数，继承 `ModbusParameter`，实现 `IDriverParameterKey`。TCP：`Server`/`ProtocolId`；RTU：`PortName`/`Baudrate`/`DataBits`。驱动自动选择协议 |
| `MewtocolDriver` | `NewLife.Panasonic` | PLC-4 | Mewtocol 原生协议驱动，实现 `IDriver`。直接通过 TCP 发送 Mewtocol 协议帧，支持 RCP/WCP/RCS/WCS 命令 |
| `MewtocolNode` | `NewLife.Panasonic` | PLC-4 | Mewtocol 设备节点，实现 `INode`。承载 `TcpClient`、`NetworkStream` 等运行时连接状态 |
| `MewtocolParameter` | `NewLife.Panasonic` | PLC-4 | Mewtocol 连接参数，实现 `IDriverParameter` 和 `IDriverParameterKey`。包含 `Server`、`Station`（站号）、`Block`（块号）、`Timeout` |

### 2.3 关键流程

#### Modbus TCP 驱动初始化（含心跳检测）

```mermaid
sequenceDiagram
    participant App as 消费方应用
    participant Driver as PanasonicDriver
    participant Param as PanasonicParameter
    participant Node as PanasonicNode
    participant Modbus as ModbusTcp
    participant PLC as 松下PLC

    App->>Driver: 创建驱动实例
    App->>Param: 配置连接参数（Server/Host/功能码）
    App->>Driver: Open(device, param)
    Driver->>Driver: CreateModbus(device, node, param)
    Driver->>Modbus: 创建ModbusTcp(Server, ProtocolId)
    Driver->>Modbus: 配置 Tracer, Log
    Driver->>Driver: StartHeartbeat() 启动心跳定时器
    Driver-->>App: 返回 Modbus 通道
```

#### Mewtocol TCP 读写流程

```mermaid
sequenceDiagram
    participant App as 消费方应用
    participant Driver as MewtocolDriver
    participant Node as MewtocolNode
    participant PLC as 松下PLC

    App->>Driver: Open(device, param)
    Driver->>Node: 创建 TcpClient 连接
    Node-->>Driver: 返回 MewtocolNode

    App->>Driver: Read(node, points)
    Driver->>Driver: 构建 Mewtocol 帧 %01#01#RCPDT1000001{checksum}\r
    Driver->>PLC: TCP 发送
    PLC-->>Driver: 响应帧 %01#01#${data}{checksum}\r
    Driver->>Driver: 解析响应数据
    Driver-->>App: 返回读取结果
```

#### Modbus RTU 串口初始化

```mermaid
sequenceDiagram
    participant App as 消费方应用
    participant Driver as PanasonicDriver
    participant Param as PanasonicParameter
    participant RTU as ModbusRtu
    participant PLC as 松下PLC Modbus网关

    App->>Driver: 创建驱动实例
    App->>Param: 配置串口参数（PortName/Baudrate/Host）
    App->>Driver: Open(device, param)
    Driver->>Driver: CreateModbus(device, node, param)
    Note over Driver: 检测 PortName 非空 → RTU 模式
    Driver->>RTU: 创建ModbusRtu(PortName, Baudrate, DataBits)
    Driver->>RTU: 配置 Timeout, Tracer, Log
    Driver-->>App: 返回 ModbusRtu 通道
```

### 2.4 心跳检测与自动重连

`PanasonicDriver` 内建连接健康管理机制（仅 Modbus TCP 模式）：

| 特性 | 说明 |
|------|------|
| 心跳间隔 | 可配置，默认 30 秒 |
| 检测方式 | 定期发送 Modbus 读保持寄存器请求（FC03）验证连接 |
| 自动重连 | 检测到连接断开后自动使用原参数重新建立连接 |
| 重试次数 | 可配置，默认最多 3 次 |
| 重试间隔 | 可配置，默认 1000ms |
| 启用开关 | `AutoReconnect` 属性控制，默认启用 |

## 3. 设计决策

| 决策 | 选项 | 选择 | 理由 |
|------|------|------|------|
| 主协议实现方式 | 纯 Modbus TCP / 自定义松下协议 | Modbus TCP | 松下 PLC 支持 Modbus TCP 网关模式，复用 NewLife.Modbus 成熟协议栈，降低维护成本 |
| Mewtocol 协议策略 | 完整实现 / 最小可用 | 最小可用（TCP 基础读写） | Mewtocol 完整协议复杂，仅覆盖 RCP/WCP/RCS/WCS 命令，满足基本读写需求 |
| 串口支持方案 | 自定义串口驱动 / 复用 NewLife.ModbusRTU | 复用 NewLife.ModbusRTU | NewLife.ModbusRTU 已提供成熟 Modbus RTU/ASCII 实现，避免重复造轮子 |
| 驱动注册机制 | `[Driver]` 特性 / 手动注册 | `[Driver("PanasonicPLC")]` + `[Driver("PanasonicMewtocol")]` | 遵循 NewLife.IoT 规范，支持 IoTEdge 和 ZeroIoT 自动发现驱动 |
| 参数模型 | 独立参数类 / 字典传参 | 独立类（PanasonicParameter / MewtocolParameter） | 强类型参数，编译期类型安全，IDE 智能提示友好；实现 `IDriverParameterKey` 支持连接复用 |
| 统一 vs 分离驱动 | 单驱动入口 / 协议各自独立驱动 | 双驱动（PanasonicDriver + MewtocolDriver） | Modbus TCP/RTU 共用一个驱动入口（参数自动选择），Mewtocol 独立驱动（协议差异大） |
| 目标框架 | 多框架 / 仅 netstandard2.1 | net45+net461+netstandard2.0+netstandard2.1 | 兼容老旧工业控制系统（多运行于 Windows 7/10 .NET Framework 环境） |
