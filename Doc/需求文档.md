# NewLife.Panasonic 功能说明

> 版本：v3.0 | 日期：2026-07-22

本文档描述 NewLife.Panasonic 的愿景、核心功能和能力边界。所有功能已完成开发且通过测试验证，详细实现见[架构设计](架构设计.md)，状态追踪见[功能清单](功能清单.md)。

## 1. 背景与愿景

### 1.1 系统定位

松下 PLC 通信协议库，基于 NewLife.IoT 标准框架，为 .NET 应用提供松下 PLC 设备的三种通信驱动：**Modbus TCP**、**Modbus RTU**（串口）和 **Mewtocol TCP**（松下原生协议）。

作为 NewLife IoT 生态中的 PLC 驱动组件，与 NewLife.Modbus（Modbus 协议栈）、NewLife.ModbusRTU（串口 Modbus）和 NewLife.IoT（IoT 标准接口）协同工作，与 IoTEdge、ZeroIoT 平台原生集成。

### 1.2 愿景

成为 .NET 生态下松下 PLC 通信协议的首选驱动库，专注于松下 PLC 通信协议（Modbus TCP、Modbus RTU、Mewtocol），与 NewLife 物联网平台（IoTEdge、ZeroIoT）无缝集成，为工业自动化场景提供稳定、高效的设备连接能力。

## 2. 核心目标

| 编号 | 目标 | 所属层级 | 一句话描述 |
|------|------|----------|------------|
| PLC | 松下PLC协议驱动 | 基础层 | 三协议合一驱动（Modbus TCP / Modbus RTU / Mewtocol TCP/串口），覆盖松下 PLC 主流通信场景。已全部实现 |

## 3. 功能需求

### 3.1 PLC — 松下PLC协议驱动

全部 8 个功能点已完成开发并通过测试验证。

- **PLC-1 PanasonicDriver 统一驱动入口**：松下 PLC 驱动入口，实现 `IDriver` 接口，通过 `[Driver("PanasonicPLC")]` 注册。根据 `PanasonicParameter` 中 `Server`（TCP）或 `PortName`（RTU）字段自动选择 Modbus TCP 或 Modbus RTU 通道。
- **PLC-2 PanasonicNode Modbus 节点**：Modbus 设备节点，继承 `ModbusNode`，实现 `INode` 接口，承载通道、地址、功能码等运行时状态。
- **PLC-3 PanasonicParameter 连接参数配置**：统一连接参数，继承 `ModbusParameter`，实现 `IDriverParameterKey`。TCP 模式配置 `Server`/`ProtocolId`/`Host`，RTU 模式配置 `PortName`/`Baudrate`/`DataBits`。驱动根据已填字段自动选择协议。
- **PLC-4 Mewtocol TCP 原生协议**：`MewtocolDriver` 通过 Mewtocol 原生协议 TCP 通道直连松下 PLC，通过 `[Driver("PanasonicMewtocol")]` 注册。支持 RCP（读寄存器）、WCP（写寄存器）、RCS（读触点）、WCS（写触点）命令。根据地址前缀自动路由：触点类地址（R/Y/X/L/T/C/S 开头）走 RCS，其余走 RCP。内建 XOR 校验和计算。
- **PLC-5 连接健康检查与自动重连**：在 `PanasonicDriver` 中内建 `TimerX` 心跳检测（默认 30 秒间隔）、断线自动重连（最多 3 次，间隔 1 秒）和超时重试机制。仅 Modbus TCP 模式生效，`AutoReconnect` 属性控制启停。
- **PLC-6 Modbus RTU 串口支持**：合并到 `PanasonicDriver`/`PanasonicParameter` 中，通过 Modbus RTU 协议支持串口（RS232/485）连接松下 PLC Modbus 网关。`PortName` 非空自动启用 RTU，与 TCP 模式共用同一驱动入口。
- **PLC-7 Mewtocol 串口支持**：在 `MewtocolDriver`/`MewtocolParameter` 中新增串口传输方式，通过 `PortName`/`Baudrate`/`Parity`/`DataBits`/`StopBits` 参数配置。驱动根据 `Server`（TCP）或 `PortName`（串口）自动选择传输方式，复用同一帧格式。
- **PLC-8 Mewtocol 高级命令（HELP/RUN/PROG）**：在 `MewtocolDriver` 中追加三个公开方法：`ReadStatusAsync`（HELP 命令，读取 PLC 状态/错误码）、`SetRunModeAsync`（RUN 命令，切换至运行模式）、`SetProgramModeAsync`（PROG 命令，切换至编程模式）。

## 4. 🧊 暂缓清单

以下功能经评估后未纳入当前版本，未来可根据需求重新评估：

| 功能 | 暂缓理由 | 解冻前提 |
|------|----------|----------|
| 松下 MEV/MEW 专用协议 | 松下早期专有协议，使用范围极窄，绝大多数场景可通过 Modbus TCP 或 Mewtocol 覆盖。无公开协议规范 | 有明确客户需求且可获取协议规范时重新评估 |

## 5. 不做什么

- **松下 PLC 底层串口协议**：不直接实现 RS232/RS485 串口通信，仅通过 Modbus TCP 网关或 Modbus RTU 标准协议与松下 PLC 通信。
- **Web 管理界面**：不包含可视化配置工具或后台管理页面。
- **Mewtocol 编程功能**：不包含松下 PLC 的专用编程功能（如上载/下载梯形图程序、RUN/PROG 模式切换等 Mewtocol 高级命令）。
- **非 .NET 语言支持**：本项目为 .NET 生态组件，不提供其他语言实现。
