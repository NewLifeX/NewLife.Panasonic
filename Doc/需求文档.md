# NewLife.Panasonic 需求文档

> 版本：v1.0 | 日期：2026-07-22

本文档描述 NewLife.Panasonic 的愿景、核心目标和功能方向。完成状态在[功能清单](功能清单.md)中追踪，详细设计在[架构设计](架构设计.md)中展开。

## 1. 背景与愿景

### 1.1 系统定位

松下PLC协议库，基于 NewLife.IoT 标准框架和 Modbus TCP 协议，为 .NET 应用提供松下 PLC 设备的通信驱动。作为 NewLife IoT 生态中的 PLC 驱动组件，与 NewLife.Modbus（Modbus 协议栈）和 NewLife.IoT（IoT 标准接口）协同工作。

### 1.2 愿景

成为 .NET 生态下松下 PLC 通信的首选驱动库，与 NewLife 物联网平台（IoTEdge、ZeroIoT）无缝集成，为工业自动化场景提供稳定、高效的设备连接能力。

## 2. 核心目标

| 编号 | 目标 | 所属层级 | 一句话描述 |
|------|------|----------|------------|
| PLC | 松下PLC协议驱动 | 基础层 | 基于 Modbus TCP 实现松下 PLC 通信协议，提供标准化的驱动接口 |

## 3. 功能需求

### 3.1 PLC — 松下PLC协议驱动

- **PLC-1 PanasonicDriver**：松下 PLC 驱动入口，实现 `IDriver` 接口，创建 Modbus TCP 通道并连接松下 PLC 设备。
- **PLC-2 PanasonicNode**：Modbus 设备节点，实现 `INode` 接口，表示一台松下 PLC 设备，承载通道、地址、功能码等运行时状态。
- **PLC-3 PanasonicParameter**：连接参数配置，实现 `IDriverParameter` 接口，配置 TCP 服务器地址、端口、协议标识、站号和功能码。

## 5. 不做什么

- 不实现松下 PLC 的底层串口协议（如 RS232/RS485 直接通信），仅通过 Modbus TCP 网关通信。
- 不包含 Web 管理界面或可视化配置工具。
- 不包含松下 PLC 的专用编程功能（如上传/下载梯形图程序）。
